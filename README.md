# Tiny · landing page (chatboti)

Landing page pro aplikaci **Tiny** — chatboti do výuky pro učitele ZŠ a SŠ.

**Živá verze:** [ondrejmrkus.github.io/tiny-chatboti](https://ondrejmrkus.github.io/tiny-chatboti/)

## Co tu je

Jednostránkový landing page představující Tiny učiteli, který aplikaci nezná. Cílem stránky je, aby se učitel zaregistroval a aplikaci si vyzkoušel ve své hodině.

Sekce: hero · co Tiny je · jak to funguje · co dostává učitel · katalog 11 chatbotů (uspořádáno podle Bloomovy taxonomie) · pro koho · testimonialy z pilotu · trust block · FAQ · CTA · footer.

## Struktura

Jeden `index.html` soubor, žádné závislosti. Fonty z Google Fonts (Inter + Fredoka). Aktuálně černobílé — barevná identita přijde při finálním designu (stačí přepsat CSS proměnné `--accent*` a `--warn*` v `:root`).
